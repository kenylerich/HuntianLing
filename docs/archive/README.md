## Summary

This directory stores documents that are no longer current but must remain available for traceability. Archive a document here only after the active replacement, review decision, or superseding requirement is recorded.

## Archive Rules

- Archived documents are historical records and should not be edited for routine cleanup.
- Move a document here when `archive_after` passes, the document is superseded, or the review owner decides it should no longer guide implementation.
- Keep the original document pair and `.i18n.yaml` sidecar together.
- Set `doc_status: archived` on archived documents outside this index.
- Link the active replacement or review decision from the archived document when one exists.
